# 严谨代码审查指南

审查代码时，请按以下 5 大维度系统性展开：

1. **逻辑正确性与边界处理**：空指针、数组越界、并发竞态、异步时序。
2. **性能与资源管理**：不必要的闭包分配、频繁 DOM 重绘、未清理的定时器/监听器。
3. **架构与可维护性**：模块解耦、单一职责、清晰的命名与可测性。
4. **安全与防护**：SQL/命令注入、XSS、敏感信息泄漏、未校验的输入。
5. **改进方案与重构示例**：明确给出修改前后的对比代码（Diff 风格）。
